# RN Engenharia — Central Financeira de Obras

## Objetivo
Centralizar e publicar a posição financeira semanal das obras da construtora, com rastreabilidade, fila de divergências e decisão humana.

## Contexto
O projeto começa por uma obra representativa e depois se expande às obras ativas da construtora. A API do Sienge é desejável; o upload governado é o caminho alternativo.
