# Objetivo do projeto

Criar uma Central Financeira de Obras construtora-first para consolidar semanalmente realizado e comprometido, mostrar saldo e necessidade de caixa e rastrear cada número até sua origem.

## Sucesso

- posição semanal publicada com data de corte;
- divergências tratadas com responsável/evidência;
- diretoria consulta somente posições validadas;
- expansão posterior para todas as obras ativas.

## Fora do primeiro ciclo

Incorporadora/SPEs, IA no caminho crítico, substituição do Sienge/Prevision, conciliação bancária automática, projeção de 12 semanas sem gate de dados.
